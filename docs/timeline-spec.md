# タイムラインの仕様（編集ページ）

対象：Matsuko Editor のブラウザ版（`src/matsuko-editor.html`）と、そこから作るデスクトップ版
目的：自由にトラックを重ね、クリップを選び・動かし・切り・詰める、実際の編集に使える操作をそろえる
作成日：2026-11-26

## 1. 考え方

- **見た目は確定デザインどおり**：クリップの色、トラック名の欄、再生ヘッドの形は変えない。
- **操作は一般的な編集ソフトに合わせる**：Premiere Pro などに慣れた人が戸惑わない操作にする。
- **初心者でも迷わないようにする**：キーボードショートカットには必ず画面上のボタンかメニューも用意する。
- **ショートカットは変えられる**：「ファイル → 環境設定 → ショートカット」で一覧を見て、キーを割り当て直せる（Ctrl＋, でも開く）。ほかの動作と同じキーを選ぶと、そちらからは外れる。変更はブラウザに保存する。「ヘルプ → キーボードショートカット」も同じ画面を開く。

## 2. データの形

```
P.tracks: [{ id, kind: 'v' | 'a', name, h, hide, lock, mute, solo }]
           並びは上から V3, V2, V1, A1, A2, A3（映像は番号の大きいものが上に重なる）
P.clips:  [{ id, tr, type, start, in, out, m?, link?, ...種類ごとの値 }]
           type = 'media'（素材） / 'title'（テロップ） / 'adj'（調整レイヤー）
           start = タイムライン上の開始（秒）
           in, out = 素材の中の範囲（秒）。テロップ・調整レイヤーは in=0、out=長さ
           link = 同じ素材から作った映像と音声を結ぶ番号。片方を動かすともう片方も動く
           映像系：x, y（位置 %）、scale（拡大率 %）、rot（回転 °）、op（不透明度 %）
           音声系：vol（音量 dB）
           テロップ：label、st（種類）、sz（大きさ）
P.pin, P.pout: 書き出し範囲（秒）
```

- 1つのトラックの中で、クリップは重ならない（置いたときに、下にあったクリップは上書きされる）。
- 前の形式（`seq` / `titles` / `bgm`）で保存されたプロジェクトは、開いたときに自動で新しい形に変換する。

## 3. 表示

| 項目 | 内容 |
|---|---|
| トラック名の欄 | 名前（V1・A1 など）、映像は「表示」、音声は「M（ミュート）」「S（ソロ）」、共通で「ロック」。右クリックでトラックの追加・削除 |
| 目盛り | 拡大率に合わせて間隔が変わる（1 フレーム〜5 分）。クリック・ドラッグで再生位置を動かす |
| 拡大・縮小 | タイムラインの一番下にある目立たないスライダー（マウスを乗せると濃くなる）、`+` / `-` キー、Ctrl＋ホイール。`\` キーで全体を表示 |
| スクロール | 横はホイール（Shift＋ホイール）とスクロールバー、縦はトラックが多いとき。再生中は再生ヘッドを追いかける |
| 選択中 | 白い枠。リンクしたクリップは一緒に選ばれる |
| ロック中 | 斜線を重ね、選択・移動・削除の対象外にする |
| スナップ | 有効なときは、クリップの端・再生ヘッド・イン点／アウト点・0 秒に吸い付き、黄色い線を出す |

## 4. 操作

### 選択
| 操作 | 結果 |
|---|---|
| クリック | そのクリップだけを選ぶ（リンク先も一緒に） |
| Shift / Ctrl（⌘）＋クリック | 選択に足す・外す |
| Alt＋クリック | リンク先を含めずに選ぶ |
| 何もないところからドラッグ | 囲んだクリップを選ぶ（Shift で足す） |
| 何もないところをクリック・Esc | 選択を外す |
| Ctrl＋A | すべて選ぶ（ロック中のトラックは除く） |

### 移動
| 操作 | 結果 |
|---|---|
| ドラッグ | 時間とトラックを動かす。映像は映像トラック、音声は音声トラックの間だけ。重なった部分は上書きする |
| Ctrl（⌘）を押しながら離す | 挿入：置いた位置より後ろのクリップを後ろへずらす |
| Alt を押しながら離す | 複製：元のクリップは残す |
| Alt＋← / → | 選んだクリップを 1 フレームずつ動かす |

### 長さの調整（トリミング）
| 操作 | 結果 |
|---|---|
| クリップの端をドラッグ | その端だけを動かす。素材の長さと、となりのクリップを越えない |
| Ctrl（⌘）を押しながら端をドラッグ | リップル：後ろのクリップも一緒にずれ、すき間ができない |

### 分割・削除・すき間
| 操作 | 結果 |
|---|---|
| S キー・分割ボタン | 再生ヘッドの位置で分割する（選んでいればそのクリップだけ、選んでいなければロックしていない全トラック） |
| 分割ツール（C）でクリック | クリックした位置で分割する |
| Delete | 削除（すき間を残す） |
| Shift＋Delete | リップル削除（後ろを詰める。ほかのトラックも、その範囲が空いていれば一緒に詰める） |
| すき間を右クリック →「すき間を詰める」 | そのすき間を詰める |

### コピー・リンク
| 操作 | 結果 |
|---|---|
| Ctrl＋C / X / V | コピー／切り取り／再生ヘッドの位置に貼り付け（元のトラックに、上書きで） |
| Ctrl＋D | 選んだクリップのすぐ後ろに複製する |
| Ctrl＋L | リンクする・リンクを解除する |

### 置く
| 操作 | 結果 |
|---|---|
| 素材パネルからトラックへドラッグ | 落とした位置とトラックに置く（上書き。Ctrl で挿入）。映像の素材は、音声もリンクして下の音声トラックに置く |
| 素材の「＋」 | 選んだクリップの後ろ（なければ V1 の最後）に挿入する |
| カットページ「仮編集へ追加」 | V1 に挿入する（無音を除いたときは複数のクリップに分かれる） |
| T キー・テロップの追加 | 再生ヘッドの位置の、空いている映像トラック（なければ新しいトラック）に置く |

### 再生ヘッド
- Space：再生／停止
- ← / →：1 フレーム移動
- Shift＋← / →：1 秒移動
- ↑ / ↓：前／次の編集点へ移動
- Home / End：先頭／最後へ移動
- I / O：書き出し範囲

## 5. インスペクタ

| 選んでいるもの | 表示する内容 |
|---|---|
| 映像・画像のクリップ | 素材・開始・イン・アウト・長さ。モーション（位置 X・Y、拡大率、回転）と不透明度を数値とスライダーで変えられ、プレビューと書き出しに反映する |
| 音声のクリップ | 素材・開始・長さ。音量（dB）を変えられ、再生と書き出しに反映する |
| テロップ | 文字・種類・大きさ・開始・長さ |
| 複数 | 選んだ数と合計の長さ。削除・リップル削除・リンクのボタン |

## 6. 再生と書き出し

- 映像は、下のトラック（V1）から上へ順に重ねる。表示を切ったトラックは描かない。
- 音声は、ミュートしたトラックは鳴らさない。ソロのトラックがあれば、ソロのトラックだけを鳴らす。
- 映像の素材は、映像トラックでは映像だけ、音声トラックでは音だけを使う（リンクした音声クリップが音を受け持つ）。
- 番組の長さは、全トラックで一番後ろにあるクリップの終わりまで。

## 7. 今回は作らないもの

- キーフレーム（時間とともに値を変える）
- クリップの速度の変更
- トランジション
- トラックの高さを変える
- ネスト（シーケンスの入れ子）

これらは、エフェクトページの本実装（M6 以降）でまとめて扱う。
