# Matsuko Editor Alpha 0.1.0

アルファ版（試用版）の最初のリリースです。機能や画面は、これからも変わります。大切な作品は、プロジェクトのフォルダーごと控えを取りながら使ってください。

- 素材の読み込み（動画・音声・画像）、サムネイル・波形・作業用の軽い動画（プロキシ）の作成
- カット編集（素材の選別・イン点とアウト点・無音の検出・仮編集）と、タイムラインでの編集
- テロップ（42 種類のスタイル・フォント・PC のフォント）、トランジション（42 種類）、音量のゲインラインとフェード
- 台本アプリ（Scenario Writer）の連携ファイルの取り込みと、台本の行とクリップの紐づけ
- MP4（H.264・AAC）の書き出し、書き出し前のチェック
- 自動更新（起動したときに新しい版を確かめる）、ログの保存（ヘルプ → ログを保存…）

このアルファ版のインストーラーには、コード署名がありません。Windows では「Windows によって PC が保護されました」→「詳細情報」→「実行」、Mac では右クリック →「開く」で入れてください（導入の手引き：https://github.com/482q7g2rx9-cloud/Yahibo-Matsuko/blob/v0.1.0/docs/install-guide.md ）。
