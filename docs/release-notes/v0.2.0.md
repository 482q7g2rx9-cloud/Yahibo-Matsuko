# Matsuko Editor Alpha 0.2.0

アルファ版の 2 回目の更新です。エフェクト・録音・台本連携を広げました。大切な作品は、プロジェクトのフォルダーごと控えを取りながら使ってください。

- 色補正：明るさ・コントラスト・彩度・色温度・色かぶり・ガンマ、プリセット 7 種、LUT（.cube）の読み込み
- エフェクトページ：エフェクトの一覧、ぼかし・モザイク・周辺を暗く、適用前と適用後の見比べ
- キーフレーム：位置・拡大率・回転・不透明度を時間で動かす（リニア・ベジェ・停止・イン・アウト）、動きのプリセット 8 種
- トラッキング：映像の中のものを囲んで追い、テロップなどを追従させる・モザイクやぼかしで隠す
- テロップのアニメーション：登場 9 種・退場 6 種（タイプライター、1文字ずつ など）
- 調整レイヤーの範囲：四角の中だけに色補正・エフェクトを掛ける（キーフレームで動かせる）
- オーディオページでのナレーションの録音（台本の行ごと、動画に合わせて録音、カウントイン、テイクの採用と配置）
- 台本アプリのプロジェクトファイル（.swdx）の取り込みと、絵コンテの画像の表示

キーフレームで動くクリップがあると、書き出しに時間がかかります。初めて録音するとき、Mac ではマイクの使用の許可を聞かれます。

このアルファ版のインストーラーには、コード署名がありません。Windows では「Windows によって PC が保護されました」→「詳細情報」→「実行」、Mac では右クリック →「開く」で入れてください（導入の手引き：https://github.com/482q7g2rx9-cloud/Yahibo-Matsuko/blob/v0.2.0/docs/install-guide.md ）。0.1.0 を入れている PC には、起動して少したつと更新の知らせが出ます。
