# Matsuko Editor 導入の手引き（学校向け）

学校のパソコンに、管理者の権限なしで Matsuko Editor を入れて使うための手順です。

## 1. 動くパソコン

| OS | 版 | メモリ | そのほか |
|---|---|---|---|
| Windows | 10（1809 以降）・11、64 ビット | 8GB 以上（4K の素材を使うなら 16GB） | WebView2（Windows 11 には最初から入っている） |
| macOS | 11 Big Sur 以降（Apple シリコン・Intel） | 8GB 以上 | |
| Linux | Ubuntu 22.04 以降など | 8GB 以上 | 動画の再生に GStreamer のプラグイン（下を参照） |

- 素材の 1 時間あたりの目安：作業用の軽い動画（プロキシ）に 1〜2GB の空きが要ります。
- インターネットは、入れるときと更新を確かめるときに使います（GitHub に届くこと）。編集はオフラインでもできます。

## 2. ダウンロード

<https://github.com/482q7g2rx9-cloud/Yahibo-Matsuko/releases/latest> を開き、「Assets」から選びます。

| パソコン | ファイル |
|---|---|
| Windows | `Matsuko-Editor_<版>_x64-setup.exe` |
| Mac（Apple シリコン：M1 以降） | `Matsuko-Editor_<版>_aarch64.dmg` |
| Mac（Intel） | `Matsuko-Editor_<版>_x64.dmg` |
| Linux | `Matsuko-Editor_<版>_amd64.AppImage`（更新できる）、または `.deb` |

Mac の種類は、アップルメニュー →「この Mac について」の「チップ」（Apple M1 など）か「プロセッサ」（Intel）で分かります。

## 3. 入れる

### Windows

1. `…-setup.exe` をダブルクリックします。
2. 「Windows によって PC が保護されました」と出たときは、「詳細情報」→「実行」を押します（署名のない版のとき）。
3. 管理者のパスワードは求められません。入れる場所は、使っている人のフォルダー（`%LOCALAPPDATA%\Matsuko Editor`）です。
4. スタートメニューに「Matsuko Editor」ができます。

- 使う人ごとに入れます（同じパソコンでも、ほかの人のアカウントには入りません）。
- WebView2 がないパソコンでは、入れるときに自動で取ってきます（インターネットが要ります）。

### macOS

1. `.dmg` を開き、「Matsuko Editor」を「アプリケーション」フォルダーへドラッグします。管理者の権限がないときは、自分のホームの「アプリケーション」フォルダー（なければ作る）か「デスクトップ」に置いても使えます。
2. 初めて開くとき、「開発元を確認できない」と出たら、アプリを右クリック →「開く」→「開く」を押します（署名・公証のない版のとき）。
3. 素材のフォルダーへのアクセスや、マイクの使用（ナレーションの録音）を聞かれたら「許可」を押します。

### Linux

- AppImage：ファイルを右クリック →「プロパティ」→「実行可能」にしてから、ダブルクリックで開きます。
- deb：`sudo apt install ./Matsuko-Editor_<版>_amd64.deb`（管理者の権限が要ります）。
- 動画が映らないときは、`gstreamer1.0-plugins-good` と `gstreamer1.0-libav` を入れます。

## 4. 更新

- 起動して少したつと、新しい版があれば知らせます。「ヘルプ → 更新を確認…」→「更新して起動し直す」で入れ直せます。管理者の権限は要りません。
- 起動のたびに確かめないようにするには、「ファイル → 環境設定… → 一般」（Mac はアプリの名前のメニューの「設定…」）の「更新」で「起動したときに確認する」を外します。
- 一斉に版をそろえたいときは、新しい setup.exe / dmg で入れ直しても同じです（作ったプロジェクトはそのまま使えます）。

## 5. プロジェクトの置き場所

- プロジェクトは 1 つのフォルダー（`project.json` と `cache` フォルダーなど）です。初めは「ドキュメント」の中の「Matsuko Editor」に作ります。
- 素材（動画・音声・画像）はコピーせず、元の場所を使います。USB メモリーやネットワークのフォルダーの素材を使うときは、プロジェクトと素材を一緒に持ち運ぶと、別のパソコンでもそのまま開けます。見つからない素材は、メディアページの「リンクし直す」で選び直せます。
- オーディオページで録ったナレーションは、プロジェクトの中の「録音」フォルダーに WAV で入ります。
- `cache` フォルダーは作業用です。消しても、開いたときに作り直します。

## 6. 困ったとき

- 「ヘルプ → ログを保存…」で、記録を 1 つのファイルにまとめて保存できます。不具合を知らせるときに添えてください。
- 「ヘルプ → ログのフォルダーを開く」で、記録のある場所を開けます。
- 消すとき：Windows は「設定 → アプリ」から「Matsuko Editor」をアンインストール、Mac はアプリをゴミ箱へ。プロジェクトのフォルダーは消えません。
